### Justification
The kin8nm dataset (forward kinematics of an 8-link robot arm, 2000 rows × 8 features) is highly non-linear: the strongest linear correlation is theta3 at r=0.52 and the sum of squared single-feature correlations is ~0.38, predicting a linear R² ceiling around 0.4. Linear regression confirmed this exactly (RMSE 0.2019, R² 0.4152), so ~60% of variance lies in feature interactions — exactly the regime where gradient boosting excels. A first GBM with depth=3 underperformed (RMSE 0.1795) because shallow stumps cannot capture the multi-joint trigonometric interactions; widening to depth=6 with 800 trees and a low learning rate (0.03) plus stochastic subsampling (0.8) produced the best result: CV RMSE 0.1499 ± 0.0073, R² 0.678 ± 0.019. This beats the best random forest (RMSE 0.1662) by ~10%, which is roughly 20× the cv_rmse_std — a statistically clear win, not a tie. Linear-family models (ridge, lasso) were skipped because with only 8 uncorrelated features there is no multicollinearity for ridge to fix and no irrelevant features for lasso to prune; they would have produced essentially the same RMSE as plain linear regression. A single decision_tree was skipped because it is uniformly dominated by the bagged/boosted ensembles on smooth non-linear surfaces. Fold heterogeneity is low (cv_rmse_std ~5% of mean, r2_std ~0.02), so the CV estimate is trustworthy.

### Caveats
(1) I evaluated 6 model configurations, not an exhaustive grid — a finer GBM sweep (e.g., depth ∈ {5,6,7}, learning_rate ∈ {0.02,0.03,0.05}, n_estimators with early stopping) could shave another 1–2% off RMSE, but gains are clearly into diminishing-returns territory (depth 5→6 only delivered 1.6%). (2) Hyperparameters were chosen by inspecting CV scores, so the reported RMSE is mildly optimistic; a held-out test set or nested CV would give an unbiased estimate. (3) The target is symmetric (skew 0.07) and uncapped (max 1.45 is not a round ceiling), so a log/Box-Cox transform is unlikely to help — I did not pursue one. (4) No spatial/temporal columns are present, so geographic generalisation is not a concern, but kin8nm samples are i.i.d. simulator draws — performance on real robot data with sensor noise or calibration drift could differ. (5) I did not try XGBoost/LightGBM or a small MLP; on this benchmark MLPs historically reach R² ≈ 0.85+, suggesting the largest untapped gain is switching model family rather than tuning further within sklearn's GBM. (6) Fit time ~28 s is acceptable for a 2k-row dataset but would scale poorly; if retraining frequency matters, the depth=5/n=500 variant (RMSE 0.1524, ~15 s) is a reasonable speed/accuracy tradeoff.

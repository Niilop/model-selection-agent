### Justification
Ridge regression (alpha=1.0) achieves CV RMSE 2.295 ± 0.135 and R² 0.493, statistically tied with Random Forest (RMSE 2.2937 ± 0.081, R² 0.492) — the gap of 0.001 RMSE is two orders of magnitude smaller than either model's fold-to-fold std. Given the tie, ridge is preferred because it is ~180× faster (55 ms vs 9.8 s), fully interpretable, and matches the data's structure: 7 highly inter-correlated physical measurements (length/diameter/weights all measure 'size') with moderate, evenly-spread linear correlations to Rings (0.52–0.61, no dominant feature). L2 shrinkage is exactly the right tool for that collinearity pattern. Lasso (RMSE 2.323) was slightly worse, suggesting all features carry some signal and aggressive sparsity hurts. Both gradient boosting variants (RMSE 2.321–2.322) and the constrained decision tree (2.387) underperformed, indicating the Rings–size relationship is essentially smooth and near-linear once collinearity is handled — there are no strong feature interactions for tree ensembles to exploit on just 1600 training rows. All non-trivial models plateau near RMSE ≈ 2.30, which is the well-known abalone biological-noise floor; further gains require feature engineering or a different signal, not a different model family.

### Caveats
1) **Target skew not exploited**: Rings has skew 1.18 with a long right tail (max 29 vs mean 9.9); a log(Rings) or sqrt(Rings) transform would likely reduce RMSE on older abalones for every model, especially the linear ones — this was not tested here. 2) **CV optimism**: I tuned alpha and tree depths by inspecting CV RMSE on the same 5 folds, so the reported 2.295 is mildly optimistic; a held-out test pass or nested CV would give a more honest estimate. 3) **Untested variants**: I did not test ElasticNet, polynomial/interaction features for ridge, HistGradientBoosting, or much wider GBM/RF grids; given the tight clustering near the noise floor, gains would likely be marginal (<2%). 4) **Sex feature absent**: the canonical abalone dataset includes a categorical Sex (M/F/I) feature that is informative — its absence here caps the achievable R² around 0.5; if Sex can be reintroduced, expect meaningful improvement. 5) **Small dataset (n=2000)**: fold std of 0.08–0.14 RMSE means model rankings within ~0.05 RMSE are not reliably distinguishable. 6) **No spatial concerns** — no lat/long features, so geographic generalisation isn't an issue here.

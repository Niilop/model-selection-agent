### Justification
The dataset (768 rows, 8 building-physics features predicting heating load Y1) shows strong but clearly non-linear structure. The linear baseline lands at RMSE 2.93 (R² 0.91), driven mostly by the two dominant correlations (X5=0.89, X4=0.86), but a single depth-8 decision tree slashes RMSE to 0.55 — a 5.3× improvement that proves substantial feature interactions exist (e.g., glazing × orientation × surface area). Gradient boosting with n_estimators=500, max_depth=4, learning_rate=0.05 achieves CV RMSE 0.3751 ± 0.027 (R² 0.9986), comfortably beating random forest's 0.5096 ± 0.045 by ~0.13 RMSE — about 3× the winner's own std, so the gap is real, not noise. The tuned GB is also more stable across folds (std dropped from 0.056 at default settings to 0.027). Ridge offered no benefit over OLS (slightly worse, 3.00 vs 2.93), confirming there is no multicollinearity penalty to ease, so I skipped Lasso for the same reason — with only 8 informative features, implicit feature selection has nothing to gain. Decision tree was kept only as a non-linearity probe.

### Caveats
(1) I did not run an exhaustive grid: only three GB configurations and one RF/DT variant each were tested; an XGBoost/LightGBM model or a more careful (subsample, min_samples_leaf) sweep could squeeze marginal gains, but at RMSE ~0.38 on a target with std 10.1 we are already at R²>0.998 and likely at the noise floor of the data. (2) The tuned GB hyperparameters were chosen after seeing CV scores on the same folds, so the reported 0.3751 is mildly optimistic; a held-out test set or nested CV would give a more honest estimate. (3) Y1 has skew 0.36 and is not capped (max 43.1 is not a round number), so a log/Box-Cox transform is unlikely to help materially here — unlike for Y2 or capped housing-price targets. (4) No spatial or temporal columns are present, so geographic generalisation is not a concern; however, this dataset comes from simulated buildings with only 12 distinct building shapes, meaning real-world novel geometries may extrapolate worse than CV implies. (5) Dataset size (768 rows) is small — the GB model fit in 3 s, so retraining on new data is cheap, but the absolute RMSE estimate has limited precision (the ±0.027 std is itself estimated from just 5 folds).

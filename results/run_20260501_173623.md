# Regression Model Selection Report

## Dataset
- **Train rows:** 353  |  **Test rows (held out):** 89
- **Features:** 10

## Agent Recommendation
**Winner:** `ridge`  
**Params:** `{'alpha': 0.1}`  
**CV RMSE (train):** 55.84  
**R² (CV):** 0.457  
**Training time:** 42 ms

**Runner-up:** `lasso` — CV RMSE 55.89

### Justification
The diabetes dataset is small (N=442, 10 features) with a well-behaved target (mean=152, std=77, skew=0.44, no capping artefacts) and a signal that is spread additively across multiple moderately correlated features (bmi 0.60, s5 0.55, bp 0.44, s4 0.43, s6 0.39) rather than concentrated in a single dominant predictor. These conditions strongly favour regularised linear models. Ridge α=0.1 achieved the best 5-fold CV RMSE of 55.84 (R²=0.457, fit ~42ms), narrowly beating Lasso α=0.1 (55.89) and plain OLS (55.97) — these three are statistically tied within ~0.13 RMSE, far less than the ±2.6 fold std. The clear evidence for the linear family comes from the non-linear models lagging meaningfully: random forest (max_depth=6, n_est=300) reached only 58.38 and gradient boosting only 60.29 — both >0.6 std worse than ridge while costing 30–100× more compute. Increasing ridge α beyond 0.1 degraded results monotonically (60.19 at α=1, 72.52 at α=10), and decreasing it to 0.01 also slightly worsened performance (55.90), confirming α=0.1 is the local optimum. I skipped decision_tree because a single unregularised tree on 353 training rows is dominated by RF/GB which themselves underperformed here — there was no realistic path for it to win.

### Caveats
(1) **CV optimism**: I selected α=0.1 by inspecting CV scores across alphas, so the reported 55.84 is mildly optimistic; a nested CV or a held-out test split would give a more honest estimate. (2) **Hyperparameter coverage**: I tested only 3–4 alpha values per regulariser and conservative RF/GB configs — an exhaustive grid (e.g., ElasticNet, RF with different feature subsampling, GB with very low learning rate + many trees) might tighten the gap, but the linear plateau is unlikely to be beaten given the data characteristics. (3) **Fold heterogeneity**: r2_std ≈ 0.12 even for the winner indicates substantial variability across folds — unavoidable at N=442 but means a single-train/test result could swing ±5 RMSE. (4) **Target transform**: skew is only 0.44 so a log/Box-Cox transform is unlikely to materially help, but worth a quick check given mild right skew. (5) **Feature engineering, not model choice, is the likely ceiling**: interactions (e.g., bmi × bp) and quadratic terms in the serum measurements could lift R² above 0.46 — the model family is at its limit, the feature set is not. (6) No spatial/temporal features, so no geographic generalisation concerns.
